Launcher: enable texture-no-wait by default after a measured A/B

A clean steady-state A/B in the 3D world: default switches gave 0.2-0.7 fps
with textures 28-206 ms and copying back 317-393 ms; with
VICTORY_TEXTURE_NO_WAIT=1 and in-flight fetch off it gave 1.0-3.7 fps with
textures 27-73 ms and copying back 12-177 ms (about 3-5x). endevslab measured
the same switch cutting a 964 ms mapping-lock wait from a 2780 ms frame.

Enable VICTORY_TEXTURE_NO_WAIT=1 by default in run.ps1 with a
-NoTextureNoWait comparison switch, and record both the A/B numbers and the
new largest bucket (heap buffers, 357-1231 ms) in the README. In-flight fetch
is left as before; a per-pipeline GPU timing run confirmed it does not name
the title's draws, so that bucket needs another instrument.
